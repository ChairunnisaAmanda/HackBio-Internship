# HackBio Internship Repository

In September 2024, I had the opportunity to participate in the HackBio internship program, following the Data Science/Machine Learning Engineer track. As a free intern, I was able to complete four stages, although I couldn't fully finish Stage 4. This experience allowed me to work collaboratively with groups, enhancing both my technical and teamwork skills. 

The stages were diverse and challenging: Stage 0 focused on article writing, Stage 1 involved summarizing a scientific paper, Stage 2 required conducting gene expression analysis, and Stage 3 was the highlight—integrating machine learning and differential expression analysis to identify key biomarkers in lymphoid leukemia. This internship provided me with invaluable hands-on experience in applying data science techniques to real-world problems.

Stage 2 and 3 were conducted using R, in stage 2 we used basic R function. Meanwhile for Stage 3, we used packages from Bioconductor.
